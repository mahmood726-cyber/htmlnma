Network Geometry & Transitivity Inspector

A pre-flight check for network meta-analysis. Enter your direct treatment comparisons; this tool decides whether an NMA is even feasible (one connected network of at least three treatments) and describes the geometry — degree, density, the most-connected node and any multi-arm trials. It estimates nothing: the graph is exact and deterministic. Fully offline — no network, no dependencies.

Direct comparisons

Formats:
A, B — one 2-arm comparison (weight 1)
A, B, 3 — 3 studies on the A–B edge
T1: A, B, C — a multi-arm trial (all pairwise edges; flagged)
Lines beginning # are comments. Names are matched verbatim.
Provenance. Connectivity by union–find. nmaFeasible = (components == 1 && nodes >= 3); a 2-node network is a pairwise meta-analysis, not an NMA. Density = edges / C(n,2). Multi-arm trials contribute all pairwise edges (correct for geometry, though those edges are statistically correlated). Parallel edges aggregate by summing study counts. The transitivity checklist is qualitative — the tool never asserts transitivity holds.
